GEANT4 simulations + quick and dirty analysis code.

### Prerequisites
<!---->
This project uses [Nix](https://nixos.org/) to manage GEANT4 dependencies. Install it by following the instructions [here](https://nixos.org/download/).
Ensure [flakes are enabled](https://nixos.wiki/wiki/Flakes#Enable_flakes_permanently) in your Nix configuration.
<!---->
### Usage
<!---->
One flake at the root holds a dev shell per project, named after the project's directory. From the repo root:
<!---->
```bash
nix develop .#SiDiode                    # or any project; `nix develop` lists them
cmake -S . -B build && make -C build -j  # in the project directory, where the shell starts
cd build && ./sim run.mac
```
<!---->
Each shell has Geant4 (with Qt and all its datasets), ROOT, and [Analysis-Utilities](https://github.com/ewtodd/Analysis-Utilities), all from the Analysis-Utilities version pinned in `flake.lock`; bump it with `nix flake lock --update-input utils`.
<!---->
A multithreaded run merges its per-thread files into a single `output<run>.root` when it ends (`include/OutputMerger.hh`). Outputs are kept out of git, on `/labdata`, reached through each project's `macros/root_files` symlink. Analysis macros live in `macros/` and run with `root -l Macro.cpp+`.
<!---->
The projects are grouped by collaboration: [ANSG](ANSG/README.md), [MDvDM](MDvDM/README.md), [MUSIC](MUSIC/README.md), [PSI](PSI/README.md). [AGENTS.md](AGENTS.md) has the layout and coding rules.
